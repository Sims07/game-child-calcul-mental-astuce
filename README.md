🪄 Maths Flash CE2 - Le Club des Astuces
Une application web interactive, ludique et colorée conçue pour aider les enfants de CE2 à maîtriser le calcul mental grâce à des stratégies simples et guidées (passage par la dizaine, astuces du ￼ et du ￼).
✨ Fonctionnalités
L'application est structurée en 3 modes complémentaires :
1. 💡 1. Les Astuces (Visualisation)
Explications visuelles et colorées pour comprendre comment calculer rapidement :
￼ Passer par la dizaine : ￼
￼ L'astuce du ￼ : ￼
￼ L'astuce du ￼ : ￼
2. 👣 2. Entraînement Pas à pas
L'enfant est guidé étape par étape selon la méthode choisie. L'application vérifie chaque étape intermédiaire avant de valider le résultat final.
3. ⚡ 3. Mode Défi Rapide
Pour tester ses réflexes une fois la méthode comprise, avec un indice visuel d'astuce disponible à tout moment en cas d'hésitation.
4. 🏆 Système de récompense
Gagne des étoiles et déclenche des animations de confettis et effets sonores joyeux à chaque bonne réponse !

🚀 Déploiement sur GitHub Pages
Cette application est 100 % autonome (un seul fichier HTML sans compilation ni dépendances à installer).
Étapes pour publier votre version :
1. Créer un dépôt GitHub :
￼ Allez sur GitHub et créez un nouveau dépôt public (ex: ⁠maths-ce2⁠).
2. Ajouter les fichiers :
￼ Ajoutez le fichier ⁠index.html⁠ à la racine de votre dépôt.
￼ Ajoutez ce fichier ⁠README.md⁠.
3. Activer GitHub Pages :
￼ Dans votre dépôt, allez dans Settings > Pages (dans le menu latéral gauche).
￼ Sous Build and deployment, sélectionnez la branche ⁠main⁠ (ou ⁠master⁠) et conservez le dossier ⁠/ (root)⁠.
￼ Cliquez sur Save.
En moins d'une minute, votre application sera accessible en ligne à l'adresse :
⁠https://<votre-pseudo-github>.github.io/<nom-du-depot>/⁠
